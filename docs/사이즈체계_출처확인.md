# 사이즈 체계 변환표: 출처 확인 TODO

`src/lib/sizeSystems.js`의 변환표는 **근사 / 출처 확인 필요** 값이에요. 화면과 코드 주석에도 같은 플래그(`근사/출처 확인 필요`)가 나와요.

이 표를 만든 환경은 외부 사이트에 접속할 수 없어서, 아래 표준·규격의 원문을 열어 수치를 확인하지 못했어요. 값은 "호칭이 무엇을 뜻하는지"(예: 국내 남성 상의 95/100/105는 가슴둘레 cm 호칭)에 기댄 것이고, 원문과 대조한 값이 아니에요.

## 쓰임새와 우선순위

- 후기, 사이즈표, 판매글 실측이 모두 없을 때만 보여주는 **가장 낮은 우선순위**의 참고값이에요.
- 추천 계산(여유분 판정, 사이즈 점수)에는 쓰지 않아요. 호칭은 몸 치수에 가까운 값이고 옷 실측(단면×2)과 달라서예요.
- 성별을 모르거나 여성이면 숫자 호칭(95/100)을 풀지 않아요.
