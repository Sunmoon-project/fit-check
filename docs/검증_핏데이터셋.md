# 핏 데이터셋 검증

## 현재 상태

**아직 실제 데이터로 측정하지 않았어요.** 이 문서에는 실제로 측정한 정확도 수치가 없어요.

스크립트를 만들 때 쓴 환경은 외부 네트워크(DNS)가 막혀 있어서 공개 데이터셋 사이트에 접속하지 못했어요. 그래서 데이터 형식, 내려받는 주소, 이용 조건(라이선스)은 확인하지 못했어요. `--demo` 옵션으로 합성 샘플을 돌려 스크립트가 끝까지 도는지만 확인했어요. 합성 샘플의 출력 수치는 실제 정확도가 아니에요.

## 목적

공개 핏 데이터셋(Rent the Runway, ModCloth 등 후기에 키·몸무게·사이즈·핏 라벨이 들어 있는 데이터)으로, 앱의 "비슷한 체형 후기 투표" 방식(`bodySimilarity`)이 핏 라벨을 얼마나 맞히는지 재현 가능하게 재 보는 거예요.

## 사용자가 할 일

1. 데이터셋을 직접 내려받으세요. 이 저장소는 원본 데이터를 담지 않아요.
2. 내려받기 전에 데이터셋 페이지의 이용 조건(라이선스, 연구용 제한 여부)을 직접 확인하세요. 확인하지 못했어요.
3. 파일을 `data/` 또는 `.cache/`에 두세요. 두 폴더는 `.gitignore`에 들어 있어요.
4. 파일이 JSON lines(한 줄에 후기 하나)인지 확인하세요. 아니면 변환이 필요해요.
5. 실행하세요.

```
npm run validate:fit -- data/파일이름.json
FIT_DATASET_PATH=data/파일이름.json npm run validate:fit
npm run validate:fit -- data/파일이름.json --out validation-output/result.json
npm run validate:fit -- --demo
```

`validation-output/`도 `.gitignore`에 들어 있어요. 데이터 경로 없이 실행하면 안내만 나오고 끝나요.

## 기대하는 입력 형식

한 줄에 JSON 객체 하나이고, 아래 필드를 읽어요. (공개 데이터셋의 필드 이름을 기억에 의존해 맞춘 것이고, 실제 파일로는 확인하지 못했어요. 이름이 다르면 `scripts/lib/fitMetrics.mjs`의 `normalizeRow`를 고치세요.)

| 필드 | 예 | 정규화 |
|---|---|---|
| `fit` | `fit`, `small`, `large` | `true`, `small`, `large` |
| `size` | `8`, `M` | 대문자 문자열 |
| `item_id` (또는 `item`) | `123` | 문자열 |
| `height` | `5' 8"` | cm (ft/in 변환), `170cm`도 허용 |
| `weight` | `137lbs` | kg (lbs 변환), `60kg`도 허용 |

키·몸무게·핏·사이즈·상품 id 중 하나라도 없거나 해석 못 하는 행, 키 120~220cm 또는 몸무게 30~200kg을 벗어난 행은 제외하고, 제외 개수와 사유를 출력해요.

## 지표 정의

- **이웃 투표 예측**: 한 행(사람)마다 같은 상품·같은 사이즈를 산 다른 사람 중 `bodySimilarity`가 기준(기본 55, `--threshold`로 변경) 이상인 사람들의 핏 라벨을 유사도 가중 다수결로 모아 예측해요. 자기 자신은 뺀 leave-one-out 방식이에요. 최다 득표가 동률이면 특정 라벨로 기울이지 않고 예측 불가로 처리하며, 동률 건수는 리포트에 따로 나와요.
- **정확도**: 예측이 가능했던 행 중 실제 라벨과 같은 비율. 이웃이 없어 예측하지 못한 행은 빼고, 대신 **커버리지**(예측 가능한 행의 비율)를 같이 보여줘요.
- **비교 기준**: 항상 가장 흔한 라벨로 답했을 때의 정확도. 이웃 투표가 이보다 낫지 않으면 체형 매칭이 라벨을 맞히는 데 도움이 된다고 말하기 어려워요. 단, 비교 기준은 전체 행 기준이고 이웃 투표 정확도는 예측 가능한 행 기준이라 분모가 달라요.
- **라벨별 precision/recall**, **혼동행렬**(행=실제, 열=예측), 표본 수.
- **보조 통계**: 사이즈별 라벨 분포, 키·몸무게 구간별 정사이즈 비율.

## EASE_RULES는 여기서 검증하지 않아요

`EASE_RULES`(옷 치수 - 신체 치수 여유분 기준)를 검증하려면 상품의 실측 사이즈표가 필요해요. 이런 후기 데이터에는 사이즈표가 없을 가능성이 커서(실제 파일은 확인하지 못했어요) 이 스크립트는 `EASE_RULES`를 측정하지 않아요. 측정하지 않은 것을 측정한 것처럼 쓰지 않으려고 따로 적어 둬요. 이 스크립트가 보는 건 후기 투표(`bodySimilarity`) 부분뿐이에요.

## 한계

- 해외, 특히 여성복 중심 데이터일 가능성이 커요. 한국 쇼핑몰 사이즈 체계와 체형에 그대로 일반화하기 어려워요.
- 키·몸무게는 스스로 적은 값이고, 핏 라벨은 주관적 평가예요.
- 상품 사이즈표가 없어서 사이즈 번호가 상품마다 같은 뜻이 아닐 수 있어요. 그래서 같은 상품·같은 사이즈끼리만 비교해요.
- 연구용 라이선스일 수 있어요. 서비스에 데이터를 그대로 쓰거나 재배포해도 되는지는 확인하지 못했으니 직접 확인하세요.
- 합성 샘플(`--demo`)의 수치는 아무 의미가 없어요.
